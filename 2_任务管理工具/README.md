# 日序 Rixu Planner

一款本地优先的长期规划、每周目标、每日任务与习惯打卡工具。新版采用纯静态网页架构，不需要 npm、Electron 或命令行窗口。

## 快速启动

- 双击 `日序.exe` 或桌面唯一的“日序”快捷方式：默认打开完整深度管理。
- 深度管理右上角可打开可拖动、可完整交互的“口袋版”，或选择“固定桌面”模式。
- 子页面左上角提供“返回总览”，右上角 `×` 可完整退出。
- 兼容入口 `启动日序.cmd` 只负责转交给 EXE，日常无需使用。

`日序.exe` 是轻量原生启动器，以系统 Edge 的应用模式承载纯静态页面，并在窗口存续期间维护高清图标与置顶状态。它还注册 `rixu://` 本地协议，让网页版能够可靠地打开、关闭或切换桌面模式。

## 功能

- 年度、季度、月度规划
- 年度规划内置长期战略卡片；任务卡片与习惯卡片可拖动排序
- 每周目标与每日任务（核心）
- 任务支持执行时间、截至时间、置顶与取消置顶
- 运动、饮水、阅读等每日习惯打卡
- 每日自动分析并生成 Markdown 执行简报，保存到 `执行情况/`；管理页提供图表、源码切换和 PNG 图片分享，可复制图片并直接打开本机微信
- 桌面模块显示、排序与折叠状态配置
- 桌面首屏默认最多展示三组，向下滚动可查看更多已启用模块
- 看板卡片、完成反馈、启动过渡及轻量微交互
- 浏览器本地存储，无账号、无后端
- Web App Manifest 与 Service Worker，部署到 HTTP/HTTPS 后可直接由 Chrome 安装为 PWA

## 网页入口

- 桌面小组件：`web/index.html?widget=1`
- 深度管理：`web/index.html?manage=1`

在 Chrome 中打开深度管理页后，可通过“投放、保存和分享 → 安装页面为应用”创建本地应用。直接使用项目自带的快捷方式或 EXE 不需要执行这一步。

## 源码结构

- `web/`：完整网页应用与 PWA 文件
- `assets/`：日序 Logo、PNG 与 ICO 图标
- `native/RixuLauncher.cs`：轻量 Windows 启动器源码
- `执行情况/`：按日期保存的每日执行简报
- `功能开发日志.md`：按时间记录每次功能更新；后续更新需同步追加一行
- `日序.exe`：已编译的无控制台启动程序
